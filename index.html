04 — Method

From synthesis to certificate.

Five stages, in the same order, for every compound we release — whether it is a single vial or a fifty-vial run.

01 / Intake

Source material

Inputs come from validated pharmaceutical-grade suppliers and are checked against their certificates before anything enters production.

02 / Synthesis

Solid phase

Solid-phase synthesis gives sequence-level control, with intermediate purification carried out throughout the run rather than at the end.

03 / Assay

Analytical testing

Each batch is run for purity by HPLC against a ≥98% threshold, and for molecular identity by mass spectrometry.

04 / Review

Batch verification

Results are reviewed independently of the bench that produced them. A lot number is issued only against a pass.

05 / Record

Documentation

The Certificate of Analysis is filed per lot: purity, molecular weight, CAS number, lot identifier and test date, retrievable on request.
